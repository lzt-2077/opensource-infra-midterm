# 开源软件生态中的「基础设施层」及其供养结构

多源数据融合分析 ｜ 2026-11-16 ｜ 单人为组

代码仓库：<https://github.com/lzt-2077/opensource-infra-midterm>（私有；如需评阅请邀请协作者，或改为 Public）

围绕一个问题：**开源里那层「所有人都依赖、但没人直接卖」的技术基础设施，究竟由谁供养？**
用 7 个相互独立的数据源（两个包生态全量库、GitHub 账号画像、基金会财务文件、学术文献、成员域名映射、npm/Maven 试点），构建 2015-01 → 2025-12 的 132 个月度依赖图快照，回答三个核心问题（Q1 谁供养 / Q2 公司造地基还是用现成 / Q3 资金与技术重要度是否匹配）。

### 3.2 一键顺序

在仓库根目录（即 `作业/` 的上一级）执行：

```bash

python 作业/整合/重建-包账号.py
python 作业/整合/重建-仓库主体.py
python 作业/整合/重建-Q2.py          # → Q2-重算.csv（8,175 / 483 / 7,692 / 94.1%）

# ② Q1 主口径
python 作业/整合/三列模型-重建.py     # → 三列模型-主图口径.csv / -透视.csv / -旧口径.csv
python 作业/整合/Q1-三列模型.py       # → Q1-三列模型-法人类型.csv / Q1-口径核对.csv / Q1-底基构成.csv

# ③ 融合表（约 1–3 分钟，读 197 MB + 320 MB）
python 作业/整合/构建.py              # → 包级融合表-crates.parquet（171,730 × 30）
                                      #   → 包-账号-主体.parquet（422,586 行；公开仓库不含此全量表）

# ④ 五张图
python 作业/可视化/作图.py            # → 可视化.html
```

底基序列与 N90 序列由 `依赖图/年代图/入驻/75-底基-无可选.py` 与 `76-N90-主图.py` 生成（已在完整仓库内，产物随 `依赖图/` 提供）。

完整数据 4.8 GB 未上传；`raw样本/` 为字段结构与清洗链条的代表性样本。

| `S1-crates-样本.csv` | 2,000 | 85 KB | `6fbed075c6ae41e61c073ca29c086367` |
| `S1-versions-样本.csv` | 5,000 | 266 KB | `573e42dc5dd205ce4513c5e50b32263b` |
| `S1-crate_owners-样本.csv` | 2,000 | 89 KB | `13e8fd93c927ec8db7348a2140895bf4` |
| `S2-pypi-样本.parquet` | 3,000 | 327 KB | `8cccd235520d019ef7b4dc08061e7759` |
| `S3-github-contributors-样本.jsonl` | 2,000 | 2.6 MB | `073f41944a467c830bd7152e34fcc3c6` |

> 去标识：`整合/样本-包账号主体.csv` 已去掉 `账号显示名` 列（该列可能含真实姓名），只保留公开登录名；42 万行全量账号表不随公开仓库提交，可由 `重建-包账号.py` / `构建.py` 在本地重建。

校验：`md5sum -c` 或 `certutil -hashfile <file> MD5`。

完整数据的口径提醒：
1. `dependencies.csv` 的 `crate_id` 列是**依赖目标**，`version_id` 才是发出依赖的版本；
2. `optional` 是 `t`/`f` 字符串，`astype(bool)` 会把 `'f'` 判为 True（本项目实际踩过）；
3. `kind`：0 = normal，1 = build，2 = dev；主分析只用 `kind=0`；
4. 同一 `(version_id, crate_id, kind)` 可能因 `target` 不同出现多行（0.21%）。

## 5. 复现时最容易踩的四个坑（都在报告里写过）

1. **口径**：全文主图 = 2025-12-14 时点、`kind=0` 且 `optional=false`、每 crate 取时点前最新版本。旧表 `_三列-cargo-填赞助.csv`（含 optional）会给出另一套数（公司 3.99%），不要混用。
2. **标签源**：Q1 用命名空间级级联标签（覆盖 87%），人工核验只有 293 条（覆盖 40.4%）；Q2 用账号级标签（190 个公司账号）。两套标签不要互换，否则 94.1% 会变成 84.9%。
3. **样本减少**：融合表 171,730 行 < 主图 174,800 个包，差的 3,070 个只存在于图指标（见报告 §3.1 的样本减少说明）。
4. **B 级数字**：聚类 ARI 0.570/0.584/0.620、排名规则退出率 4.39%/88.94% 来自会话内实验，无脚本；引用时必须标注（见 `依赖图/00-数据溯源总表.md`）。
